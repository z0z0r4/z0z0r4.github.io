Sentinel Node

我觉得这个设计非常巧妙，学到了。

在链表的首位添加不记录 value 也不计入 size，对应 next 或者 prev 为自身的哨兵节点，只占位，为 Head 节点和 Tail 节点提供了一个的前驱和后继节点，同时应该 next 或者 prev 为自身，可以一直 ->next 或者 ->prev，避免边界条件的问题。

然后还能直接设计成回环，又省一个节点，tql
