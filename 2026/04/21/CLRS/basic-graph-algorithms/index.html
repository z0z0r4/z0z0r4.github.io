图由顶点集合和边集合组成，写成 G=(V,E)G=(V,E)G=(V,E)，其中VVV是顶点集合，EEE是边集合。

其中边用两个顶点组成的二元组表示，比如 (u,v)∈E(u, v) \in E(u,v)∈E 表示图 GGG 中 uuu 和 vvv 之间有一条边，其中 uuu 指向 vvv

Graph Representation

有两种表示：

  • 邻接表
  • 邻接矩阵

这两种设计在各个操作的差别见 CS61B Graph Representation

其中还有 CSR（Compressed Sparse Row）表示，将邻接表压缩到两个数组中，缺点是无法动态添加边，适合静态图的存储。

表示的不同有不同的算法设计，复杂度也大不相同。

22.1-3
有向图 G=(V,E)G=(V,E)G=(V,E) 的转置是图 GT=(V,ET)G^T=(V,E^T)GT=(V,ET)，其中 ET={(v,u)∈V×V:(u,v)∈E}E^T=\{(v,u) \in V \times V : (u,v) \in E\}ET={(v,u)∈V×V:(u,v)∈E}。因此，图 GTG^TGT 就是将有向图 GGG 中所有边的方向反过来而形成的图。对于邻接链表和邻接矩阵两种表示，请给出从图 GGG 计算出 GTG^TGT 的有效算法，并分析算法的运行时间。

首先考虑邻接表的，直接按节点获取所有邻居，然后将邻居的边反过来添加到新的图中，时间复杂度为 O(V+E)O(V+E)O(V+E)。

对于邻接矩阵，可以直接转置矩阵，时间复杂度为 O(V2)O(V^2)O(V2)。

The Diameter of a Tree

树的直径指的是树中任意两个节点之间的最长路径的长度。

可以很简单的发现直径的两端必然是树的叶子节点。

当确定直径的一端之后，另一端可以简单的从该端开始 BFS 来找到距离最远的节点得到。

有两种实现：

  • 两次 BFS/DFS
  • DP

两次 BFS/DFS

需要证明从任意节点 BFS 得到的距离最远的节点 AAA 是树的直径的一端，以及从 AAA BFS 得到的距离最远的节点 BBB 是树的直径的另一端。

树的直径可以有多种，但长度相同。

先证明第一个结论：

假设直径的两端为 AAA 和 BBB，从任意节点 SSS BFS 得到的距离最远的节点为 XXX。

分两种情况：

  • S→XS \rightarrow XS→X 不交 A→BA \rightarrow BA→B

也就是去掉一条 C -> A 的路径，添加一条 C -> S -> X 的路径，显然加上的 S -> X 比 S -> C -> A 更长，那自然比去掉的 C -> A 更长，更别说还有加上 C -> S 的路径了。

DP

树的直径也可以通过 DP 来求解。

我的想法是对于树来说，要么直径经过根节点，要么不经过根节点（在子树内）。

如果经过根节点，其直径就是两棵子树的最大深度之和加上根节点。

所以定义 dp[u] 为以 uuu 为根节点的子树的最大深度，那么对于每个节点 uuu，可以通过 dp[u] = max(dp[x]) + 1 来计算出 uuu 的最大深度，其中 xxx 是 uuu 的子节点。

则 ans = max(ans, dp[x] + dp[y] + 1)，其中 xxx 和 yyy 是 uuu 的两个子节点。

所以从叶子节点开始，向上合并子树，得到树的最大深度的同时计算出 ans，最终得到树的直径。

DFS

首先放一份 DFS 实现：

DFS 不维护队列，而是找到邻居就直接递归向下遍历，直到没有邻居了才回退。

BFS 构成一棵 BFS 树，但 DFS 构成的可能是森林（多棵树）：

  • 无向图：如果是连通图，DFS 总是能一次性访问到所有节点，所以就是一棵树。

  • 有向图：可能访问不到某些节点，需要回到 dfs 再选取剩下的节点作为起始节点，继续 DFS，直到访问完所有节点。可能有多棵树形成森林。

DFS 的时间复杂度也是 O(V+E)O(V + E)O(V+E)，因为每个节点和边都访问一次。

可以发现比 BFS 的实现，DFS 的 Vertex 的多了 start_time 和 finish_time 两个属性。这是为了方便引出以下的内容。

以下简称为属性 u.su.su.s 和 u.fu.fu.f 分别表示 uuu 的 start_time 和 finish_time。

括号化定理（Parenthesis Theorem）：对于任意两个节点 uuu 和 vvv，以下三种情况只有一种成立：

  • uuu 和 vvv 互不为祖先：[u.s,u.f][u.s, u.f][u.s,u.f] 和 [v.s,v.f][v.s, v.f][v.s,v.f] 没有交集。

  • uuu 是 vvv 的祖先：[u.s,u.f][u.s, u.f][u.s,u.f] 包含 [v.s,v.f][v.s, v.f][v.s,v.f]。

  • vvv 是 uuu 的祖先：[v.s,v.f][v.s, v.f][v.s,v.f] 包含 [u.s,u.f][u.s, u.f][u.s,u.f]。

也就是不可能存在两个节点的开始时间和结束时间交错的情况。

根据如上的三个情况，显然可以推出 Nesting of descendants’ intervals（后代区间的嵌套）：当且仅当 uuu 是 vvv 的祖先时，满足 u.s<v.s<v.f<u.fu.s < v.s < v.f < u.fu.s<v.s<v.f<u.f。

从代码上观察递归嵌套，和时间戳截取的时机可以很容易观察得出，不证明=-=。

若 vvv 是 uuu 的后代，有另一个性质——White-path theorem，白色路径定理：

vvv 是 uuu 的后代当且仅当在 uuu 的 start_time 时，存在一条全部由白色节点组成的路径从 uuu 到 vvv。

注意是充要条件。

先证明 vvv 是 uuu 的后代 ⇒\Rightarrow⇒ 在 uuu 的 start_time 时，存在一条全部由白色节点组成的路径从 uuu 到 vvv：

考虑 u=vu = vu=v 设置 uuu 的 start_time 时，显然 uuu 还是白色的（没有置灰），所以成立。

当 u≠vu \ne vu=v 时，假设 vvv 是 uuu 的任意后代，又因为满足 u.s<v.s<v.f<u.fu.s < v.s < v.f < u.fu.s<v.s<v.f<u.f，所以有 u.s<v.su.s < v.su.s<v.s。节点 vvv 在 v.sv.sv.s 才置灰，前提说此刻是 u.du.du.d，所以任意后代 vvv 都是白色节点，构成了一条从 uuu 到 vvv 的白色路径。

反过来证明，条件是存在白色路径。

假设 vvv 不是 uuu 的后代，那么取 vvv 和 uuu 的路径上的最后一个后代为 www，则满足 w.f<u.fw.f < u.fw.f<u.f。

因为 vvv 不是 uuu 的后代（也不是 www 的后代）且存在边 (w,v)(w, v)(w,v)，那么 vvv 应该在 u.su.su.s 之后、w.fw.fw.f 之前被访问到，所以 u.s<v.s<w.f<u.fu.s < v.s < w.f < u.fu.s<v.s<w.f<u.f，符合括号化定理中 vvv 是 uuu 的后代的情况，矛盾了，所以 vvv 必然是 uuu 的后代。

所以有白色路径相通则 vvv 必然是 uuu 的后代，反之亦然。

DFS 本质是贪心的，那么有能连通的白色路径当然会成为后代，成为了后代当然得有连通的白色路径…读的力竭了

根据节点间的跳转，节点间的边分类可以有：

  • 树边（Tree Edge）：DFS 过程中访问到一个未访问过（白色）的节点时的边。（即发现节点的边）
  • 前向边（Forward Edge）：由祖先节点连接后代节点。
  • 后向边（Back Edge）：由后代节点连接祖先节点。(注意，自身连接自身也算后向边)
  • 交叉边（Cross Edge）：连接两个不具有祖先关系的节点。（可能跨树，也可能在同一棵树中）

书中给出了根据颜色判断边的类型：

  • 白色节点：树边
  • 灰色节点：后向边
  • 黑色节点：前向边或交叉边（后续根据时间戳区分）

对于无向图来说，只有树边和后向边，因为无向图中不存在前向边和交叉边。

首先考虑前向边，考虑有向图的情况下，假设 (u,v)(u, v)(u,v) 是前向边，必有两条路径使得 u→vu \rightarrow vu→v 连通，比如先遍历了一条例如 u→x→vu \rightarrow x \rightarrow vu→x→v 的路径，到达 vvv 后发现边 (u,v)(u, v)(u,v) 反向无法连通，所以回溯到 uuu，之后又遍历了一条 u→y→vu \rightarrow y \rightarrow vu→y→v 的边，发现 vvv 已经是 uuu 的后代了，又回溯到 uuu，所以 u→vu \rightarrow vu→v 就成了前向边。

然而无向图不存在方向，也就是在第一次发现 vvv 之后，第二条路径 uuu <-> yyy <-> vvv 是通的，所以会一直形成树边直到回到 uuu，不存在前向边，只会后代节点连接祖先节点形成后向边。

交叉边也来自于有向图的单向性质。若 (u,v)(u, v)(u,v) 是交叉边，那么 DFS 先访问了 vvv，之后又访问了 uuu，而 uuu 有指向已被访问的节点 vvv 的边。倘若 uuu 和 vvv 之间的边是无向边，那么显然在访问 vvv 的时候就会访问 uuu，所以 uuu 和 vvv 之间的边不可能是交叉边。

依旧归于贪心。

22.3-4 和 BFS 一样提示不需要区分黑色、灰色和白色三种状态，直接用一个布尔值 visited 来表示是否访问过即可。

Topological Sort

拓扑排序指的是将所有节点线性排序，使得对任意边 (u,v)∈E(u,v) \in E(u,v)∈E，uuu 在排序中排在 vvv 之前。

观察可得必须是有向无环图，如果是有环图显然会冲突。

按照图中观察也可以猜出是先 DFS 然后按照 finish time 的逆序来排序的。

通过以下两个证明来得出 DFS 的 finish time 的逆序就是拓扑排序：

  1. 有向图是无环的当且仅当没有后向边。

    以下证明的都是逆否命题：有环当且仅当有后向边

    假设有后向边 (u,v)(u, v)(u,v)，那么 vvv 是 uuu 的祖先，其路径与边 (u,v)(u, v)(u,v) 形成一个环。

    假设有环，假设其第一个被发现的节点为 vvv，则有 (u,v)(u, v)(u,v) 和环上剩下的节点构成的一条从 vvv 到 uuu 的白色路径，则 uuu 是 vvv 的后代。而后代指向祖先的边就是后向边。

  2. 有向无环图中，对于任意边 (u,v)∈E(u,v) \in E(u,v)∈E，在 DFS 中 u.f>v.fu.f > v.fu.f>v.f。

    uuu 探索 vvv 时，考虑 vvv 的三种颜色：

    vvv 不能为灰色，否则 vvv 是 uuu 的祖先，形成后向边，与上面的证明矛盾。

    当 vvv 为白色，则 vvv 是 uuu 的后代，按照后代嵌套的性质，v.f<u.fv.f < u.fv.f<u.f。

    当 vvv 为黑色，则 vvv 在 uuu 之前就已经置黑，显然 v.f<u.fv.f < u.fv.f<u.f。

    则 u.f>v.fu.f > v.fu.f>v.f 成立，即 ∃(u,v)∈E⇔u.f>v.f\exists (u,v) \in E \Leftrightarrow u.f > v.f∃(u,v)∈E⇔u.f>v.f。

Strongly Connected Components (SCC)

强连通分量（SCC）指的是一个最大节点集合 C⊆VC \subseteq VC⊆V，使得对于任意 u,v∈Cu, v \in Cu,v∈C，都有 uuu 到 vvv 的路径和 vvv 到 uuu 的路径。

比如成环的节点集合可以是 SCC，多个环粘在一起则是一整个 SCC（单个节点也可以是）。

如上所说，图 G(V,E)G(V, E)G(V,E) 可以被转置为 GT(V,ET)G^T(V, E^T)GT(V,ET)，其中 ET={(v,u)∣(u,v)∈E}E^T = \{(v, u) | (u, v) \in E\}ET={(v,u)∣(u,v)∈E}。

观察到 GGG 中的 SCC 在 GTG^TGT 中也是 SCC。

那么书中给到的寻找 SCC 的算法是：

  1. 在 GGG 上运行 DFS，记录每个节点的 finish time。

  2. 转置图 GGG 得到 GTG^TGT。

  3. 在 GTG^TGT 上按照 finish time 的逆序运行 DFS，每次 DFS 访问到的节点集合就是一个 SCC。

注意这里的逆序指的是最外层循环遍历节点的顺序，按照这个顺序去进入 dfsvisit，而不是在 dfsvisit 内部按照 finish time 的逆序去访问邻居。
